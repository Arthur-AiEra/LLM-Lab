📊 智能投研助手代码分析报告

文件：deliberative_research_qwen_agent.py

本报告梳理了代码中的函数定义、类结构以及核心调用流程。该系统基于 Qwen-Agent 框架，模拟了一个包含感知、建模、推理、决策、报告五个阶段的智能投研分析师。

1. 函数与类清单

类型 名称 描述
Function app_gui() 程序入口 (Web)。初始化助手并启动 WebUI 图形界面。
Function app_tui() 程序入口 (终端)。初始化助手并启动命令行交互模式。
Function init_agent_service() 配置 LLM 参数，注册工具列表，实例化 Assistant 对象。
Function get_session_id(kwargs) 辅助函数。从参数中提取会话 ID，用于隔离不同用户的存储数据。
Class (Tool) CompleteAnalysisTool 核心工具。一次性执行完整的五阶段分析流程，并生成最终报告。
Class (Tool) MarketPerceptionTool 阶段1：感知。收集市场概况、指标和新闻。
Class (Tool) MarketModelingTool 阶段2：建模。构建市场状态、经济周期和风险模型。
Class (Tool) InvestmentReasoningTool 阶段3：推理。生成多个候选投资方案并评估。
Class (Tool) InvestmentDecisionTool 阶段4：决策。从候选方案中选择最优策略。
Class (Tool) GenerateReportTool 阶段5：报告。整合所有数据生成 Markdown 报告文件。
