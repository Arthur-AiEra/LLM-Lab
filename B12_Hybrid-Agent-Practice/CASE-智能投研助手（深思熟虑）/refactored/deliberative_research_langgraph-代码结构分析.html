5. 核心函数功能详解

函数名 输入 (State) 输出 (State Update) 功能描述
perception Topic, Industry, Horizon perception_data 调用 LLM 搜集市场概况、关键指标和新闻。
modeling perception_data world_model 基于感知数据，构建包含市场状态、周期和风险的内部模型。
reasoning world_model reasoning_plans 生成 3 个不同的投资分析方案（假设、方法、优劣势）。
decision world_model, reasoning_plans selected_plan 评估候选方案，选择最优方案并给出理由。
report_generation All Data final_report 整合所有阶段的信息，生成最终的文本报告。
create_research_agent_workflow - StateGraph (Compiled) 定义图的节点、边和入口点，编译 LangGraph 工作流。
