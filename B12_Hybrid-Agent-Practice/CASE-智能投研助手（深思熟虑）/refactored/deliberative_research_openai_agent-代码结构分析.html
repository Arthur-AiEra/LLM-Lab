📊 OpenAI 智能投研助手代码分析报告

文件：deliberative_research_openai_agent.py

该程序是一个基于 Streamlit 的 Web 应用，利用 OpenAI 的 Function Calling 能力，模拟了一个包含感知、建模、推理、决策、报告五个阶段的投资分析流程。

1. 函数清单

类型 名称 描述
UI / Entry main() 主程序入口。负责渲染 Streamlit 界面，处理用户输入，调用 OpenAI API，并解析返回的工具调用请求。
Core Logic perform_complete_analysis(...) 核心业务逻辑。模拟“深思熟虑”的分析过程。接收研究主题、行业和时间范围，返回格式化的 Markdown 报告。
Global TOOLS (List) 工具定义。定义了传给 OpenAI 的 JSON Schema，描述了 complete_analysis 函数的参数结构。
Global SYSTEM_PROMPT 系统提示词。定义了 AI 助手的角色（深思熟虑型分析师）和工作流程。
