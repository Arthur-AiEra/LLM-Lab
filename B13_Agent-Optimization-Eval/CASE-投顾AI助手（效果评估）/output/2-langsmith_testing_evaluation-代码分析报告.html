3. 关键函数与类功能梳理

📂 文件 1: 核心智能体

函数/类名 类型 功能描述
WealthAdvisorState TypedDict 定义图的状态 Schema，包含 query_type, processing_mode, market_data 等字段。
assess_query Node 路由节点。分析用户意图，决定走“反应式”还是“深思熟虑”路径。
reactive_processing Node 快思考。处理简单查询，具备调用 query_shanghai_index 工具的能力。
collect_data → analyze_data → generate_recommendations Nodes 慢思考链条。依次执行：确定所需数据 -> 深度分析 -> 生成建议。
create_wealth_advisor_workflow Function 构建 LangGraph 实例，定义节点（Nodes）和边（Edges/Conditional Edges）。

📂 文件 2: 测试与评估

函数/类名 类型 功能描述
ProcessingModeEvaluator Class 自定义评估器。检查 Agent 选择的模式（reactive/deliberative）是否符合预期。
create_test_dataset Function 将定义的测试用例（简单查询、复杂查询、边界情况）上传至 LangSmith。
run_evaluation Function 使用 langsmith.evaluation.evaluate 批量运行测试，并计算分数。
