## vllm 启动(必须依赖gpu)，只支持自托管模型，不能代理外部 API
```bash
python -m vllm.entrypoints.openai.api_server \
--model Qwen/Qwen3-0.6B \
--port 8000 \
--dtype float16 \
--enforce-eager \
--trust-remote-code
```



## sglang 启动(必须依赖gpu)，支持自托管模型，或直接将后端的执行目标（Backend）指向 OpenAI、Anthropic 等公共 API
```bash
python -m sglang.launch_server \
--model-path /root/autodl-tmp/models/qwen/Qwen3-8B \
--port 8001 \
--host 0.0.0.0 \
--mem-fraction-static 0.85 \ # 显存利用率 85%（4090 留一些给系统）
--max-running-requests 16 \ # 最大并发请求数
--context-length 4096 \ # 上下文长度（越短越省显存）
--chunked-prefill-size 2048 \ # 分块预填充（降低 TTFT）
--enable-metrics # 开启监控指标
```
