3. 函数功能详细解释

本节将对脚本中的每个函数进行详细说明，包括其作用、参数、返回值以及内部逻辑。

3.1. load_all_labels(labels_dir)

  • 功能： 从指定目录读取所有 YOLO 格式的标注文件（.txt），并解析其中的缺陷类别和边界框信息。
  • 参数：
    • labels_dir (str): 包含标注文件的目录路径。
  • 返回值：
    • annotations (dict): 字典，键为图片文件名（不含扩展名），值为一个列表，列表中包含该图片的所有标注框信息 (class_id, x, y, w, h)。
  • 内部逻辑： 遍历 labels_dir 下的所有 .txt 文件，对每个文件，读取其内容，按行解析出类别 ID 和归一化的边界框坐标（中心点 x, 中心点 y, 宽度, 高度），并存储到字典中。

3.2. analyze_class_distribution(annotations)

  • 功能： 统计数据集中各缺陷类别的分布情况，并计算每张图片包含的标注框数量的统计信息。
  • 参数：
    • annotations (dict): 由 load_all_labels 函数返回的标注数据。
  • 返回值：
    • class_counts (Counter): 统计各类别缺陷数量的 Counter 对象。
    • boxes_per_image (list): 列表中每个元素代表一张图片中包含的标注框数量。
  • 内部逻辑： 遍历所有标注，统计每个类别出现的次数，并记录每张图片中的标注框数量。最后打印出详细的类别分布报告，包括数量、百分比以及每张图片的标注框数量统计。

3.3. analyze_box_sizes(annotations)

  • 功能： 分析数据集中所有标注框的尺寸（宽度、高度、面积、长宽比）分布情况。
  • 参数：
    • annotations (dict): 标注数据。
  • 返回值：
    • widths (list): 所有标注框的归一化宽度。
    • heights (list): 所有标注框的归一化高度。
    • areas (list): 所有标注框的归一化面积。
    • aspect_ratios (list): 所有标注框的长宽比。
    • class_areas (defaultdict): 字典，键为类别 ID，值为该类别所有标注框的面积列表。
  • 内部逻辑： 遍历所有标注框，提取其宽度、高度、计算面积和长宽比，并按类别收集面积信息。最后打印出标注框尺寸的最小、最大和平均值。

3.4. plot_class_distribution(class_counts, output_dir)

  • 功能： 绘制缺陷类别的数量柱状图和占比饼图，并将图表保存到指定目录。
  • 参数：
    • class_counts (Counter): 各类别缺陷数量。
    • output_dir (str): 图表保存目录。
  • 内部逻辑： 使用 Matplotlib 绘制一个包含柱状图和饼图的子图，展示各类别缺陷的数量和百分比。图表标题、标签和颜色均经过美化，并保存为 PNG 格式。

3.5. plot_box_analysis(widths, heights, areas, aspect_ratios, output_dir)

  • 功能： 绘制标注框宽度、高度、面积的直方图以及宽度与高度的散点图，并将图表保存到指定目录。
  • 参数：
    • widths (list): 标注框宽度列表。
    • heights (list): 标注框高度列表。
    • areas (list): 标注框面积列表。
    • aspect_ratios (list): 标注框长宽比列表。
    • output_dir (str): 图表保存目录。
  • 内部逻辑： 使用 Matplotlib 绘制四个子图，分别展示宽度、高度、面积的分布直方图，以及宽度与高度的散点关系。图表保存为 PNG 格式。

3.6. plot_sample_images(annotations, images_dir, output_dir, samples_per_class=2)

  • 功能： 为每个缺陷类别展示指定数量的样本图片，并在图片上绘制出对应的标注框。
  • 参数：
    • annotations (dict): 标注数据。
    • images_dir (str): 包含图片文件的目录路径。
    • output_dir (str): 图表保存目录。
    • samples_per_class (int, optional): 每个类别展示的样本图片数量，默认为 2。
  • 内部逻辑： 从每个类别中随机选择样本图片，加载图片，并在图片上绘制出红色的边界框。图表保存为 PNG 格式。

3.7. plot_class_area_distribution(class_areas, output_dir)

  • 功能： 绘制各类别缺陷面积的箱线图，以可视化不同类别缺陷尺寸的分布差异。
  • 参数：
    • class_areas (defaultdict): 各类别标注框面积。
    • output_dir (str): 图表保存目录。
  • 内部逻辑： 使用 Matplotlib 绘制箱线图，展示每个类别标注框面积的四分位数、中位数等统计信息。图表保存为 PNG 格式。

3.8. check_class_imbalance(class_counts)

  • 功能： 评估数据集中类别的不均衡程度，并根据不均衡比例给出相应的处理建议。
  • 参数：
    • class_counts (Counter): 各类别缺陷数量。
  • 内部逻辑： 计算最多类别与最少类别之间的数量比，根据该比例判断类别不均衡的严重程度，并打印出过采样、类别权重、Focal Loss 等建议。

3.9. main()

  • 功能： 脚本的主入口函数，负责协调整个 EDA 流程的执行。
  • 内部逻辑：
    1. 创建输出目录 OUTPUT_DIR。
    2. 调用 load_all_labels 加载标注数据。
    3. 调用 analyze_class_distribution 进行类别分布分析。
    4. 调用 analyze_box_sizes 进行标注框尺寸分析。
    5. 调用 check_class_imbalance 评估类别不均衡。
    6. 调用一系列 plot_ 函数生成并保存可视化图表。
    7. 最后打印所有分析结果的保存路径。

4. 运行配置

脚本开头定义了几个重要的配置变量：

  • STEEL_DATA_DIR: 钢铁数据集的根目录。
  • LABELS_DIR: 标注文件所在目录（STEEL_DATA_DIR/train/labels）。
  • IMAGES_DIR: 图像文件所在目录（STEEL_DATA_DIR/train/images）。
  • OUTPUT_DIR: EDA 分析结果（图表）的输出目录。
  • CLASS_NAMES: 缺陷类别 ID 到中文名称的映射字典。
  • CLASS_NAMES_SHORT: 缺陷类别 ID 到英文短名称的映射字典，用于图表显示。

5. 总结

该 eda_analysis.py 脚本提供了一套完整的探索性数据分析流程，能够有效地帮助用户理解钢铁表面缺陷数据集的特性，包括缺陷的类别分布、尺寸特征以及潜在的类别不均衡问题。通过生成丰富的可视化图表，为后续的模型训练和优化提供了重要的数据洞察。
