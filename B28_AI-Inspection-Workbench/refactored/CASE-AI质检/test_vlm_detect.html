2. 文件与函数功能详解

📄 文件 1：test_vlm_detect.py (独立测试脚本)

功能： 该脚本是一个独立的命令行工具，用于快速测试单张图片的 VLM（视觉大模型）缺陷检测效果。

  • main() 函数：
    • 参数解析： 使用 argparse 解析 --image (图片路径)、--model (模型名称)、--save (保存路径)。
    • 前置检查： 验证图片文件是否存在，并使用 PIL.Image 读取打印尺寸信息。
    • 实例化引擎： 直接实例化 VLMDetector(model_name=args.model)。
    • 执行检测： 调用 detector.detect(args.image) 执行完整的推理链路，获取 result 对象。
    • 结果输出： 在控制台打印推理耗时、检测到的缺陷坐标及模型分析摘要，并将带有标注框的图片保存到本地（如 vlm_result_0.jpg）。

📄 文件 2：detection_engine.py (检测引擎核心封装)

全局配置与兼容性补丁：

  • _patch_aattn_forward()： 解决不同版本的 ultralytics 库中 YOLOv12 注意力机制（AAttn）权重加载格式不兼容（qkv 聚合格式 vs qk+v 分离格式）的问题，确保模型正常正向传播。
  • 全局常量： 定义了 CLASS_NAMES (英文类名)、CLASS_NAMES_CN (中文类名映射)、CLASS_COLORS (绘制检测框的预设颜色)。
  • 数据类 (DataClass)：
    • DetectionBox：封装单个缺陷的检测结果，包含类别 ID、类名、置信度以及绝对像素坐标 (x1, y1, x2, y2)。
    • DetectionResult：封装单张图片的完整检测报告，包含引擎类型、图片路径、检测框列表、VLM 文本摘要、推理耗时以及绘制好标注框的 numpy 图像数组。

核心类：VLMDetector (多模态大模型检测器)

  • __init__(api_key, base_url, model_name)： 初始化检测器。优先读取传入参数，否则通过环境变量（如 OPENAI_API_KEY）加载。并打印调试日志，方便核对当前使用的代理接口与模型。
  • _init_client()： 初始化兼容 OpenAI 格式的客户端（openai.OpenAI），支持对接本地 Ollama/vLLM 或云端 DashScope 等接口。
  • _encode_image(image_path)： 将本地图像文件读取并转化为 Base64 字符串，以便通过 API 传输给视觉模型。
  • _extract_json(text)： 从大模型返回的自然语言中“剥离”出 JSON 结构，通过正则去除 <think> 思考标签并清理 Markdown 的 ```json 代码块包裹。
  • _convert_bbox(bbox_2d, img_width, img_height)： 关键坐标转换函数。针对 Qwen3-VL 返回的 [0-1000] 归一化坐标系，执行 (coord/1000) * img_size 转换为绝对像素坐标；针对 Qwen2.5-VL 则直接透传。
  • _parse_bbox_response(reply, img_width, img_height)： 反序列化提取出的 JSON，遍历每个预测目标，转换为 DetectionBox 对象列表，并生成一段汇总检测报告文本（包含缺陷中英文对照与特征描述）。
  • detect(image_path, prompt)： 主控方法。 组装默认的 Prompt（要求模型输出固定 JSON 格式），发起请求，记录耗时，包含完整的 try-except 堆栈捕获机制。若请求成功，调用解析函数和绘图函数，最后组装并返回 DetectionResult 对象。
  • _draw_boxes(image_path, boxes)： 利用 PIL.ImageDraw 根据像素坐标在原图上画矩形框，并打上带有背景色的文字标签。

核心类：YOLODetector (专用目标检测器)

  • __init__(model_path)： 使用 ultralytics.YOLO 加载指定路径的 `.pt` 权重文件。
  • detect(image_path, conf, iou)： 执行模型预测 (predict())，提取返回的张量（xyxy 坐标、置信度、类别），转为 DetectionBox 格式，并调用自身的 _draw_boxes() 绘制标注图像。

工厂函数：create_detector(model_type, **kwargs)

  • 功能： 提供统一入口，根据传入的 model_type（"yolo" 或 "vlm"），动态分发实例化相应的检测器类，实现上层业务逻辑与底层模型框架的解耦。
