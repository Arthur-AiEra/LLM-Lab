一、Agent 数据决策核心流程

1. 特征工程 (Feature Engineering)

特征工程决定了模型的上限，算法只是逼近这个上限。

  • 时间特征处理：
      [cite_start]
    • 拆解法： 将 regDate (如 20000501) 拆解为 Year, Month, Day 独立特征 [cite: 1676]。
      • [cite_start]
    • 差值法 (Diff)： 设定 Base Date (如 2000-01-01)，计算 days_diff = current_date - base_date，反映时间的连续性 [cite: 1602]。
      • [cite_start]
    • 车龄计算： creatDate - regDate，反映车辆的实际使用时长 [cite: 1674]。
    • [cite_start]
  • 缺失值处理： 创建 _missing 标记列，并使用中位数 (Median) 填充数值型特征 [cite: 1691-1692]。
    • [cite_start]
  • 特征交互： 结合业务逻辑创造新特征，例如 功率排量比 [cite: 1696] [cite_start]或 品牌价格统计 (brand_price_mean, brand_price_std) [cite: 1438-1440]。

2. 模型选择与演进

[cite_start] [cite_start] [cite_start] [cite_start]
模型 特点 适用场景
Decision Tree (决策树)符号学派代表，可解释性强（如 C4.5, CART）[cite: 1346]。 基准测试，规则提取。
XGBoost工业界常用的 Baseline，性能强劲，支持 GPU 加速 [cite: 1424, 1431]。 结构化数据竞赛，通用预测。
CatBoost针对类别特征 (Categorical Features) 优化，无需预先 One-Hot 编码，自动处理类别特征 [cite: 1634, 1662]。 类别特征多（如品牌、车型）的场景，调参相对简单。
LightGBM速度快，内存占用低，适合大规模数据 [cite: 1617]。 海量数据快速迭代。

3. 评估指标：MAE (Mean Absolute Error)

    [cite_start]
  • 定义： 预测值与真实值之差的绝对值的平均数。MAE 是 L1 Loss [cite: 1001]。
    • [cite_start]
  • 公式： $$MAE=\frac{\sum_{i=1}^{n}|y_{i}-\hat{y}_{i}|}{n}$$ [cite: 998]。
    • [cite_start]
  • 实战标准： 在二手车价格预测中，MAE < 600 被认为是一个较好的成绩 [cite: 976]。

二、Agent 工程化实战 (Code Agent)

1. Skills 与 Function Call

    [cite_start]
  • Skills 定义： Skills = 动态 Prompt 加载器 + 程序调用器 + 动态知识库 [cite: 974]。
  • Function Call： 侧重于单纯的“执行”动作。
    • [cite_start]
  • Code Agent 模式： 利用 LLM 编写 Python 代码 (Pandas/Matplotlib) 进行 EDA (探索性数据分析)，而不是手动分析 [cite: 975]。

2. 记忆与上下文管理

    [cite_start]
  • LLM 特性： 像“金鱼”一样不带长记忆，需要外部程序管理 Context [cite: 974]。
    • [cite_start]
  • 记忆压缩： 随着对话轮数增加，Context 会无限膨胀。解决方案是引入 RAG (检索增强生成)，通过向量检索或 BM25 关键词检索，只提取相关记忆 [cite: 974]。

三、课堂精华 Q&A (避坑指南)

Q: 为什么 XGBoost 验证集 MAE 很低 (546)，提交结果也很接近 (548)，但模型效果很难再提升？
[cite_start]这说明模型没有过拟合，是一个健壮的模型。要进一步提升（降低 MAE），重点不在调参，而在于特征工程。例如引入“日期差值 (Diff)”特征，或增加“品牌价格统计”特征 [cite: 1596, 1602]。
Q: RAG (GraphRAG) 适合用来做二手车价格预测吗？
[cite_start]不适合。 RAG 主要解决文本内容相似度问题（如文档问答），而价格预测是回归问题 (Regression)，依赖数值规律和统计特征，而不是语义检索 [cite: 974]。
Q: 为什么 LLM (如 Claude/Qwen) 写的代码有时会“失忆”或报错？
[cite_start]LLM 本身不带记忆，每次交互都需要将 System Message 和历史 Context 重新传递。如果上下文过长被截断，LLM 就会“失忆”。必须通过程序（如 Agent = LLM + Memory）来显式管理 [cite: 974]。
Q: 训练时 `price_log` 特征是不是标签泄露 (Data Leakage)？
[cite_start]如果在输入特征中直接包含了 `price` 的对数形式，那就是泄露，因为这等于直接告诉了模型答案。但在处理目标变量 (Label) 时，对 `price` 取 log (使其更符合正态分布) 进行训练，预测后再 exp 回来，这是标准的处理技巧，不是泄露 [cite: 975]。
Q: 分类 (Classification) 和 回归 (Regression) 的本质区别？
  • 分类： 预测离散标签（如：男/女，好/坏）。目标是决策边界。
    • [cite_start]
  • 回归： 预测连续数值（如：房价、二手车价）。目标是最小化误差 [cite: 1395-1396]。
