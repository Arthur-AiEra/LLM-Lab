✅ Coze 工作原理与技术体系

  • AI 应用构建 SOP：需求描述 (场景示例化) → 技术选型 (是否需 Tool/RAG) → 实现细节 → 测试集验证。
  • 双轨制开发模式：
    • 高代码流派：底层框架如 LangChain, LangGraph, Qwen-Agent。IDE 辅助使用 Cursor, Trae。开源引擎有 Claw-code (Python)。
    • 低/零代码流派：通过 Coze/Dify 拖拉拽节点可视化编排；或使用 Vibe Coding 自然语言对话直出代码。
  • 核心组件对齐：
    • Agent vs Copilot：Copilot 侧重“人机协同”辅助；Agent 具备“自主规划大脑”，能根据目标自主拆解并调度工具。
    • Plugin (插件)：将外部独立 API 接口鉴权并封装，使其变为大模型可调用的 Function Call 工具。
    • Workflow (工作流)：解决单 Agent 多次交互易崩溃问题。引入了强逻辑控制，如变量聚合节点（多进一出，取分组中第一个非空值兜底）。
    • RAG 知识库：弥补幻觉。将私有数据切片、向量化存入数据库，提问时优先通过相似度召回作为上下文。

✅ 底层私有部署与生态输出

  • Docker Compose 编排：Coze Studio 本地化部署强依赖 12 个微服务容器（包含 MySQL, ElasticSearch, Redis, Minio, Milvus 向量库, NSQ 等）。命令：docker-compose up -d。
  • 脱离网页分发：配置好工作流后，支持无缝转换为微信小程序、移动应用。

✅ Coze 应用实例与极限场景

  • CASE：天气 & 新闻路由 (weather_news)：典型的意图识别工作流。利用 LLM 提取用户非结构化输入并输出标准 JSON（如提取 city, time 等入参），分发至天气 API 或新闻知识库干线。
  • CASE：抖音文案提取 & 二创：
    • 链路：URL 解析 → 提取视频资源 → 语音转文本 (ASR) → LLM（爆款文案优化师）重写。
    • 防坑机制：长链路极易超时假死，必须在耗时节点间插入输出反馈状态。
  • CASE：LLM 联网搜索 & 古诗词 Agent：结合 Bing Web 提取增量 Query；将诗词意象转化为 Prompt 喂给画图插件引擎，实现图文多模态。
  • 极限突破：Agentic RAG 医疗自救案例： 传统医疗疗法失效时，Github 前高管面对晚期癌症，将人体视为软件系统进行 Debug。他抛弃传统固定流程的 RAG，采用 Agentic RAG 模式，将高达 25TB 的白细胞 RNA 测序及医疗数据投喂给大模型。通过 AI 整合全球碎片化文献与第一性原理，筛选出 FAP 放射性同位素靶向疗法，甚至在机场触发核警报，最终实现临床治愈 (NED)。

💡 课堂精华 Q&A

Q: 目前大模型选型怎么推荐？GLM是国内版Claude吗？
国外首选 Claude Opus 4.6, GPT 5.4；国内推荐 Qwen3-Coder-Plus、GLM、Kimi 2.5、Minimax (写代码实测表现佳)。
Q: 工作流中的节点输入输出该如何定义和衔接？
具有强依赖关系。上游提取的 JSON 结构必须完美契合下游参数要求。如果不匹配，必须在中间插入「代码节点 (Code Node)」或「LLM 提取节点」进行格式转换清洗。
Q: 本地化部署大模型时，Docker 和 Ollama 怎么选？
定位完全不同。Ollama 专注于大语言模型（如 Llama3/Qwen）本体的极速拉取与推理运行；而 Docker 用于部署 AI 平台的应用层服务环境集群（如微服务及数据库）。
Q: Claw-code 嵌入到 OpenCloud 中有什么底层意义？
Claw-code 作为高代码向的 AI IDE 原码，植入后系统会将其作为底层高智能编程大脑 (Engine)，大幅强化整体架构的业务推理和逻辑编排能力。
Q: Coze 做好的智能体可以脱离网页使用吗？
可以。Coze 界面右侧支持“创建应用”，能将复杂的底层工作流封装，一键发布多端，无缝转换为微信小程序、移动应用，或提供给第三方调用的 API。
