## Coze 插件的不足
1. 稳定性极差与高度不可控（依赖第三方维护）
2. 繁琐的 API Key 门槛与潜在的隐形计费
3. 私有化本地部署版本的插件很少，需要手写代码接入第三方接口开发“自定义插件”
