1. VLM 在行业中的应用

  • 医疗病历抽取：能够提取跨语种（中文、日文、法文、德文、韩文）的患者基本信息、临床诊断和影像学表现 [cite: 1258, 1303, 1321, 1417, 1485]。
  • 车险场景识别：
    • 里程表识别：提取总里程、速度、温度及挡位以评估风险 [cite: 1560]。
    • 承保与监控：通过车辆外观判断使用环境 [cite: 1637]；识别车内驾驶员玩手机等危险行为 [cite: 1673]。
    • 损失与要素提取：评估保险杠、尾灯受损程度 [cite: 1698]；提取道路状况、天气、照明等事故要素为 JSON 格式 [cite: 1722]。
    • 防欺诈校验：对比事故前后的车型与车漆颜色，判断是否为同一辆车 [cite: 1754]。

2. 视频基础模型 (InternVideo2)

  • 核心定位：在视频识别、视频文本和对话任务中取得 SOTA 的新型视频基础模型 (ViFM) [cite: 1834]。
  • 渐进式训练 (三阶段)：(1) 未掩蔽重建捕获时空结构；(2) 与其他模态进行语义对齐；(3) 下一个 token 预测增强开放式对话能力 [cite: 1852]。
  • VidCap 标注框架：分离视频、音频、语音字幕生成器，最后通过 LLM (Crossmodal CapFusion) 融合成综合描述 [cite: 1916, 1929]。
  • 任务表现：不仅在 Action Recognition (如 Kinetics-400) 表现优异，还能准确处理视频对象时间识别、意外动作识别及视觉语言导航任务 [cite: 1894, 1934, 1978, 2001, 2013]。

3. 高效文档解析 (MinerU)

  • 核心功能：将复杂的 PDF、网页、电子书精准转换为 Markdown 或 JSON 格式 [cite: 2138, 2141]。
  • 底层技术栈：
    • 布局检测：基于 LayoutLMv3 微调 [cite: 2150]。
    • 公式识别：使用 YOLOv8 检测，UniMERNet 转换 LaTeX [cite: 2151]。
    • 文本增强：使用 PaddleOCR 提升84种语言的识别准确率 [cite: 2147, 2152]。
  • 特性：并非生成式 AI，而是布局排版+OCR的文本识别模型 [cite: 1248]；支持 CPU/GPU 本地化私有部署，优化显存使用 [cite: 2157, 2358]。

4. YOLO 与 VLM 的技术选型

  • YOLO 演进：从 v1 (划分 S×S 网格直接回归) 开启实时检测时代 [cite: 2457, 2464]；v4/v5 达到工业落地标杆 [cite: 2464]；v12 首次在保持实时性的前提下引入全局注意力机制 [cite: 2464]。

5. 核心 Q&A 精华

Q: 大模型文件较多，如何有效下载？
A: 可以在模型库（如 ModelScope）选中后打包下载，或通过 `snapshot_download` 命令直接拉取到服务器目录 [cite: 1245, 2050]。
Q: 预算有限且需针对特定地域方言习惯做优化，如何处理？
A: 无法单独部署微调大模型时，可以通过 RAG（检索增强生成）技术来提供补充上下文以解决此问题 [cite: 1245, 1249]。
Q: 蒸馏、GRPO 与教师模型在流程中是如何协作的？
A: 教师模型主要用于前置的数据集生成（梳理撰写出质量较高的 <query, answer> 训练集）。数据准备好后，再利用这些数据进行模型微调、知识蒸馏或 GRPO [cite: 1245]。
Q: 多模态模型如何处理图像与文本的联合输入？
A: 图像和文本最终都为了“信息表达的统一”。图像会被转换为 image token，文本转为 text token。它们一起送入 Embedder 映射到统一的维度（如 1024 维）进行语义相关性计算和统一编码 [cite: 1245, 1249]。
Q: Agent 架构中，单 Agent 与多 Agent 如何选择？
A: 单 Agent + Skills 是目前的主流。单 Agent 如果承担过多功能可能会导致注意力分散，但多专业 Agent 协作在实际调度中也存在复杂性问题 [cite: 1245]。
Q: InternVideo2 处理视频时，是输入原始 MP4 还是抽帧图片？
A: 直接输入原始 MP4 文件即可 [cite: 1247]。
Q: 现阶段多模态图像理解不成熟，如何构建和优化垂直业务能力（如承保专家）？
A: 需要大量业务数据标注。步骤为：1) 整理 <query, image => answer> 测试集。2) 人工审核发现缺失的能力。3) 用更高阶的模型（如 Gemini）初步标注，人工修正后作为冷启动种子数据。4) 转换为对话模式结构，使用工具进行模型微调（如 Qwen-VL） [cite: 1245, 1247]。
