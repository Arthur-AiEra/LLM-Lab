    ** 扫描当前目录并生成 requirements.txt（--force 表示如果文件已存在则覆盖）
    ```bash
    # 1. 安装 pipreqs 工具
    pip install pipreqs
    
    # 2. 扫描当前目录并生成 requirements.txt（--force 表示如果文件已存在则覆盖）
    pipreqs . --force
    ```
