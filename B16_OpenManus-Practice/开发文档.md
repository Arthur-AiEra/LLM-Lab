# 代码结构说明

- OpenManus-cy: 对 OpenManus(https://github.com/FoundationAgents/OpenManus) 做了部分更新和汉化
  子目录的以下部分来源于 OpenManus-UI： https://github.com/aliasmaya/openmanus-ui
    assets
    static
    templates
    app.py
  sandbox_main.py -> sandbox openmanus
  main.py -> openmanus

- OpenManus-gui: 针对ctrip 机票查询动态日历无法点击问题，提供 gui 解决方案
  方案 B：GUI 视觉点击 (Visual Grounding)
  当 DOM 解析失败时，引入视觉模型 (GUI Model) 直接识别屏幕坐标进行物理点击
- OpenManus-rag: 针对ctrip 机票查询动态日历无法点击问题，提供 RAG 知识注入 (Knowledge Injection) 解决方案
  通过修改 manus.py 的 System Prompt，注入“经验”，教 AI 绕过点击，直接拼接 URL




# 项目依赖
  - 申请 daytona API Key: https://app.daytona.io/dashboard/keys， 配置到 OpenManus-cy/config/config.toml


## Quick Start
1. 启动 OpenManus-UI
执行命令： https://morningfast.com/ 我想做 seo, 给我一些 seo 优化的建议
```bash
playwright install
$LLM_LAB/B16_OpenManus-Practice/OpenManus-cy/.venv/bin/python $LLM_LAB/B16_OpenManus-Practice/OpenManus-cy/app.py
```

2. 启动 OpenManus
