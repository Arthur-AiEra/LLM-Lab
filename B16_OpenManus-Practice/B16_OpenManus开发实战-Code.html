01. 环境搭建 (Environment Setup)

项目强依赖 Python 3.10+ 及 Playwright 环境。

# 1. 创建虚拟环境
conda create -n open_manus python=3.10
conda activate open_manus

# 2. 安装依赖
pip install -r requirements.txt

# 3. 初始化 Playwright (必须，否则浏览器无法启动)
playwright install

# 4. 环境变量 (.env 或 config/config.toml)
# 推荐使用 DashScope (Qwen) 或 OpenAI
export DASHSCOPE_API_KEY="sk-..."
export OPENAI_API_KEY="sk-..."

注意: 如果使用 Daytona 沙箱，需在 config.toml 中配置 Daytona API Key，否则请在本地运行 app/agent/manus.py。

04. 实战魔改：解决动态日历无法点击问题

背景： 在视频中，Agent 无法点击携程日历的 "1月30日"，因为它是 JS 动态生成的弹窗，DOM 树抓取不到。Agent 陷入死循环。

方案 A：RAG 知识注入 (Knowledge Injection)

通过修改 manus.py 的 System Prompt，注入“经验”，教 AI 绕过点击，直接拼接 URL。

# 修改文件: app/agent/manus.py

# 1. 定义经验知识 (Shortcut)
TRIP_KNOWLEDGE = """
【重要经验 - 携程机票查询】
遇到查询机票任务时，不要尝试去点击日历控件，直接构造 URL 访问：
URL格式: https://flights.ctrip.com/online/list/oneway-{出发城市Code}-{到达城市Code}?depdate={YYYY-MM-DD}
例如上海(SHA)到北京(BJS) 2026-01-30:
Target URL: https://flights.ctrip.com/online/list/oneway-sha-bjs?depdate=2026-01-30
"""

# 2. 将知识注入 System Prompt
class Manus(ToolCallAgent):
    def __init__(self, ...):
        super().__init__(...)
        self.system_prompt = f"""
        你是一个通用的 AI Agent。
        {TRIP_KNOWLEDGE}  # <--- 注入点
        
        你可以使用的工具如下...
        """

方案 B：GUI 视觉点击 (Visual Grounding)

当 DOM 解析失败时，引入视觉模型 (GUI Model) 直接识别屏幕坐标进行物理点击。
